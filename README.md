## 🎯 About

This portfolio website is a sleek, professional showcase designed to present creative work, services, and contact information in an elegant and modern interface. The site features a sophisticated navigation system, prominent footer with contact details, and a responsive design built from the ground up using semantic HTML and custom CSS styling.

Whether you're a photographer, designer, creative professional, or entrepreneur, this portfolio template provides a solid foundation for showcasing your work to potential clients and collaborators.

---

## ✨ Features

- **Modern Navigation Header** - Clean, fixed navigation bar with hover effects and smooth transitions
- **Professional Footer** - Comprehensive footer section with contact information, opening hours, address, and social media links
- **Responsive Design** - Built with mobile-first approach using flexbox layouts
- **Custom Typography** - Integration of premium fonts (IBM Plex Sans, Barlow Condensed) for professional appearance
- **Smooth Animations** - Hover effects and transitions for enhanced user experience
- **SEO Optimized** - Meta tags and semantic HTML structure for better search engine visibility
- **Dark Theme** - Modern dark color scheme with accent colors for visual appeal
- **Customizable** - Easy-to-modify CSS variables and structure for brand customization

---

## 🛠 Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Advanced styling with flexbox, custom properties (CSS variables), and animations
- **Fonts** - Google Fonts integration (IBM Plex Sans, Barlow Condensed)
- **SVG** - Logo and icon assets
